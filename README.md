# Практическая работа № 1–2 — «Яндекс Почта»

Учебный проект по анализу продукта и проектированию тестирования веб-сервиса «Яндекс Почта».

## Состав репозитория

- [Отчёт](docs/report.md) — описание продукта, карта модулей, 10 Use Case, функциональные требования, чек-лист, тест-кейсы и матрица трассировки.
- [UML Use Case](diagrams/use-case.puml) — исходник диаграммы PlantUML.
- [Чек-лист](test-artifacts/checklist.csv) — 23 проверки (CSV, разделитель «;»).
- [Матрица трассировки](test-artifacts/traceability.csv) — связь Use Case, требований, проверок и тест-кейсов.

## Как открыть диаграмму

Откройте `diagrams/use-case.puml` в PlantUML или вставьте содержимое в редактор PlantUML и экспортируйте PNG/SVG.

## Статус тестирования

Это учебный анализ существующего продукта, а не копия и не реализация Яндекс Почты. Фактические результаты не подменяются предположениями: поля отметок в чек-листе оставлены пустыми до реального прогона в отдельной тестовой учётной записи.

**Безопасность:** не добавляйте в репозиторий реальные пароли, токены, адреса личных контактов и содержимое переписки.
